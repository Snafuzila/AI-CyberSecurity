# Project 2 Documentation

This folder contains the main documentation and presentation assets for the Project 2 work in the AI-CyberSecurity repository.

The materials are primarily in Hebrew and include the project summary, presentation deck, poster, and abstract documents.

## Contents

- `מסמך מסכם בעז ולוטם.pdf` — Final project summary document in PDF format.
- `מסמך מסכם בעז ולוטם.docx` — Editable version of the final summary document.
- `מצגת בעז ולוטם.pdf` — Presentation deck in PDF format.
- `מצגת בעז ולוטם.pptx` — Editable PowerPoint presentation.
- `פוסטר בעז ולוטם.pptx` — Poster presentation file for project display or showcase.
- `תקציר פרויקט בעז ולוטם.pdf` — Short project abstract in PDF format.
- `תקציר פרויקט בעז ולוטם.docx` — Editable version of the project abstract.
- `readme.md` — Documentation index for this folder.

## Recommended reading order

1. Start with `תקציר פרויקט בעז ולוטם.pdf` to understand the project at a glance.
2. Read `מסמך מסכם בעז ולוטם.pdf` for the full project summary.
3. Review `מצגת בעז ולוטם.pdf` for the presentation flow and key findings.
4. Use `פוסטר בעז ולוטם.pptx` for a visual overview or poster session.

## Purpose of this folder

This directory acts as the project’s documentation hub and presentation archive. It gathers the deliverables needed for:

- project review,
- audience presentation,
- summary reporting,
- poster showcase,
- final documentation handoff.
